# AM32 Configurator

Reads the parameter block out of an AM32 ESC and writes it back, so the ESC can be set up
from the radio instead of from a computer. A pilot opens it to set the motor's direction and
poles, the startup and braking behaviour, the commutation settings and the ESC's own
protections.

## Where to find it

*Configuration* → *Setup* → *ESC & Motors* → *ESC Tools* → *AM32*, or *Goosky*

Lit only while the flight controller reports the ESC telemetry protocol *BLHELI32* or, from
MSP API 12.10, *GOOSKY*. Read-only while the model is armed.

**The *Goosky* tile opens this same page.** A Goosky ESC runs AM32 firmware and does not report
a brand of its own, so its settings, its reads and its saves are the ones on this page. Only
the tile, the title and the line below the title differ: once the ESC has answered, that line
reads *Goosky AM32 / EEPROM n / vX.Y*, the layout version and the firmware version being what
the ESC reported and *Goosky* the tile the page was opened from. The tile is there so that a pilot
who looks for the name on the ESC finds it. Either tile programs the ESC.

*BLHELI32* also lights the *BLHeli_S* and *Bluejay* tiles, because what the flight controller
reports is the telemetry protocol and they share it. Which of the pages fits is the pilot's
choice; opening the wrong one is refused rather than decoded, as described in
[Saving configuration](../../../../../reference/saving.md). *GOOSKY* lights only *AM32* and
*Goosky*.

## Settings

Option names are shown in the radio's language; maker abbreviations such as CW/CCW and BEC remain in English as in the maker's software.

The page opens on a safety notice, and behind it on a summary of the ESC's model, firmware
and version. *Section* switches between three groups of settings; every setting of the chosen
group is always shown, and each has its own `?`.

| Setting | What it does |
| --- | --- |
| ESC Target | Which ESC the page talks to, *ESC 1* or *ESC 2*. Shown only where the flight controller reports more than one motor. Changing it starts the connection again from the beginning, so the values on screen are replaced by the other ESC's after a few seconds. |
| Section | *Basic*, *Advanced* or *Limits*. Switching it rebuilds the list below; nothing is read from the ESC again. |

### Basic

| Setting | What it does |
| --- | --- |
| Motor Direction | *Normal* or *Reversed*. |
| Motor KV | The motor's KV rating as the ESC assumes it, 20 to 10220 in steps of 40. |
| Motor Poles | The motor's pole count, 2 to 36. |
| Startup Power | 50 % to 150 % in one-percent steps. |
| Brake on Stop | What the ESC does when the throttle closes: *Off*, *Brake* or *Active*. |
| Brake Strength | 0 to 10. |
| Running Brake Level | How hard the ESC brakes while it is running, 0 to 10. |
| Beep Volume | 0 to 11. |

### Advanced

| Setting | What it does |
| --- | --- |
| Bidirectional Mode | *Off* or *On*. |
| Sinusoidal Startup | *Off* or *On*. |
| Complementary PWM | *Off* or *On*. |
| Variable PWM Frequency | *Fixed*, *Variable* or *RPM*. |
| Stuck Rotor Protection | *Off* or *On*. |
| Timing Advance | *0°*, *7.5°*, *15°* or *22.5°*. |
| PWM Frequency | 8 kHz to 144 kHz in one-kilohertz steps. |
| Stall Protection | *Off* or *On*. |
| Interval Telemetry | *Off* or *On*. |
| RC Car Reversing | *Off* or *On*. |
| Use Hall Sensors | *Off* or *On*. |
| Sine Mode Range | 5 to 25. |
| Sine Mode Power | 1 to 10. |
| Auto Advance | *Off* or *On*. |

### Limits

| Setting | What it does |
| --- | --- |
| Servo Low Threshold | 750 us to 1250 us in two-microsecond steps. |
| Servo High Threshold | 1750 us to 2250 us in two-microsecond steps. |
| Servo Neutral | 1374 us to 1630 us in one-microsecond steps. |
| Servo Dead Band | 0 to 100. |
| Low Voltage Cutoff | *Off*, *Cell* or *Absolute*. |
| Low Voltage Threshold | 250 cV to 350 cV in one-centivolt steps, that is 2.50 V to 3.50 V. |
| Temperature Limit | 70 C to 141 C in one-degree steps. |
| Current Limit | 0 to 202 in steps of 2. 0 and 202 turn the limit off. |
| ESC Protocol | *Auto*, *Dshot 300-600*, *Servo 1-2ms*, *Serial* or *BF Safe Arming*. |

## Notes

- Opening this page stores the ESC's current limit in this flight controller's preferences on the radio,
  as whole amps and marked as this family's, where the dashboard reads it to show the current
  as an ESC load percentage and the ESC load announcement speaks it
  ([Power → Preferences](../../../power/preferences.md)). Nothing is asked of the flight
  controller for it -- the value comes out of the parameter block the page reads anyway -- and
  a visit that finds the same limit, already marked as this family's, writes nothing.
- An ESC with its limit off stores nothing: 0, and every value above 200 A, which is the highest
  limit the firmware applies. It clears a figure this family stored; a figure typed in by hand or
  from another family stays.
- The page opens behind a safety notice asking for the main and tail blades to be removed
  before the ESC is configured. Nothing else is drawn until the notice is dismissed.
- **Opening the page takes several seconds before any value appears.** The flight controller
  has to be put into forward-programming mode and pointed at the ESC first, and that sequence
  waits for the ESC twice, for about two and a half and then about five seconds, before the
  parameters are asked for at all. Changing *ESC Target* runs the same sequence again.
- Saving writes the whole parameter block to the ESC, not only the settings that were
  changed. A setting the page does not offer is written back as it was read, so a Save with
  nothing edited changes nothing in the ESC.
- Saving before this visit has read the ESC is refused with an error rather than written,
  since there would be no block to write back. Leaving the page and coming back starts again
  with nothing read, and so does *Reload* and a change of *ESC Target*.
- Leaving the page puts the settings, the model, firmware and version back to what the page
  shows before it has read anything, so a visit whose read does not arrive shows the page's
  own initial values rather than the last ESC's — which on this page need not even be the same
  ESC, because *ESC Target* starts again at *ESC 1*.
- After a successful write the page returns the flight controller to its normal state and
  reads the ESC back on its own.
- An unsaved edit is marked below the list, and is lost if the page is left without saving.
- If the ESC does not answer the write, the page says so and nothing on the screen has been
  confirmed.
