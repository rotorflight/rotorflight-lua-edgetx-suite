- **The background decoder re-reads the settings only when they changed (`functions/rfsbg`)**:
  - Every 30 s it now looks at the settings file's size and time and at the reload request beside it, the same two signals the dashboard and the service widget watch, and reads and compiles the file only when one of them moved. A quiet interval no longer opens the file twice and leaves about 16 KB of garbage; a setting changed in the tool still takes effect within the same 30 s. A missing file, a card from an earlier release, a read that fails and a radio without `fstat` behave as before. Part of #960.
