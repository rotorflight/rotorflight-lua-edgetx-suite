- **The @NovaFly RC dashboard theme (`widgets/dashboard/themes/@novafly`, `app/pages/settings/dashboard/theme_index.lua`, `docs/dashboard/novafly-theme.md`)**:
  - A free-form theme for 800 x 480 radios: one full-screen cockpit for every flight phase, a bank view of its own that reads the active PID bank's governor head speed from the flight controller and sets it on the ground, and the colour of the cockpit as its one setting, on its Settings tile and by a long press on the cockpit's head.
  - A theme may now declare the screen size it is drawn for (`screen = { w = 800, h = 480 }` in its `init.lua`); the theme selector and the settings grid list such a theme only on a radio of that size (`app/pages/settings/dashboard/lib.lua`), and the packager carries the key into the theme's index row (`bin/package/build_package.py`). The shipped themes declare none and are listed as before.
