- **A raised Log Level costs less of the dashboard's instruction budget (`lib/log.lua`, `lib/sensors.lua`)**:
  - `Log.emit` now decides a line's level once, reads the clock once and hands the same tag, level and text to the Session Logs ring and the card log; the configured level is converted only when the setting changes. At *DEBUG* a line costs about a quarter less, with *Log Session To Card* on about 40 % less, and a line below the configured level about half. For the suite's own callers, which pass the level and the setting as plain text, which lines are written, where, and what they say are unchanged; the ring, the card log and the console now carry the same time for one line, where each used to read the clock on its own.
  - The telemetry read path no longer builds a *DEBUG* line for every sensor on every read only to drop it because that line was already written once.
  - With Log Level raised, the passes after a disarm carry this cost on top of the post-flight work, and the dashboard could be stopped by EdgeTX there (#785).
