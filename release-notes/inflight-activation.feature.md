- In-flight tuning is switched per radio model and only after set-up: *Set up radio* only sets up the radio, the switch turns tuning on for that model and is greyed until the model is set up, and *Restore previous setup* turns it off. It is kept for the model's file and name, so a renamed model, or a new one that gets a deleted model's file name, starts off. A setting from before this version does not carry over (`app/pages/settings/dashboard/inflight/page.lua`, `lib/preferences.lua`).
