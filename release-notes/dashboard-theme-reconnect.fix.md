- **A reconnect no longer reloads the model's dashboard theme from the SD card (`widgets/dashboard/runtime.lua`)**:
  - Until the flight controller's UID has been read, the dashboard resolves no theme and runs no pending preferences reload, so a model with a theme of its own keeps that theme's modules loaded across the reconnect instead of releasing them for the radio's theme and reading them from the card again seconds later. The wait ends with the connection screen: if the dashboard comes up without the UID, the radio's theme is shown as before (#1008).
  - Losing the link no longer counts as a preferences change: the per-model file dropping out with the board's id is not taken as a changed file, so no reload runs at the disconnect, the model's theme stays loaded through a link loss on the ground too, and the reconnect runs no extra reload. A change found while its reload is deferred is no longer statted and logged again every second (#1009).
