- **SRXL2 ESC page (`app/pages/setup/esc_motors/srxl2`, `tasks/msp/api/srxl2_esc_config.lua`, `docs/pages/setup/esc_motors/srxl2.md`)**:
  - *Setup* → *ESC & Motors* → *SRXL2 ESC* sets the telemetry interval of a Spektrum Smart ESC and the SRXL2 channel of motor 2 on dual-motor Smart ESCs, over `MSP2_GET_SRXL2_ESC_CONFIG` / `MSP2_SET_SRXL2_ESC_CONFIG`. The tile needs MSP API 12.10 and is lit only while the flight controller reports the SRXL2 ESC telemetry protocol; saving reboots the flight controller, and the throttle rate is written back as read. A firmware without the message is told apart from a failed read, and nothing is saved from either.
  - The tool's menu now sets its ESC-protocol conditions (`ui/home.lua`) only when the reported protocol changes rather than on every pass, which takes about 150 instructions off every pass of every tool page.
