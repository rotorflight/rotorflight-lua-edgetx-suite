- **The rotary menu's rest keeps out of the pass that catches up after a stall (`widgets/dashboard/menu_roll.lua`)**: when the wheel has rested and the radio's previous pass came a second or more ago, the sweep that takes the focus back to the widget waits one pass (twice at most), so it is not billed on the same instruction budget as the telemetry and decoder work that pass catches up on. Running both in one pass is a way to exceed the budget, which disables the widget with `foreground calRefs error`.
