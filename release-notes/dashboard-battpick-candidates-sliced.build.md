- **The battery prompt reads the pack registry a few lines per widget call (`widgets/dashboard/runtime.lua`, `lib/battery_pick.lua`, `lib/flight_log.lua`)**: the dashboard built the prompt's list from the whole registry in one call -- every line parsed, every pack for the model copied and matched to a board profile -- so its cost grew with the number of packs, and a registry of a few dozen packs reached the instruction limit a widget call is stopped at. The load now takes twelve registry lines per call, in free job slots with ordinary passes between them, and the list is shown only once it is complete; with 100 packs the load runs over nine calls of under 6 000 instructions each instead of one of over 41 000. What the prompt lists, and the profile each pack resolves to, are unchanged. The Flight Log page reads the registry through the same parser (#1067). Urban's, Grid's and Deck's own picker still builds a button for every pack in one call and stops at the same limit at about 20 packs; that is #1081.
