- **A connect builds the dashboard once when the cell count is first estimated from the pack voltage (`widgets/dashboard/runtime.lua`, `docs/dashboard/themes.md`)**:
  - On a model with a cell count sensor, a count estimated from a part-charged pack (5 cells for a 6S pack at a 4.3 V maximum cell voltage) no longer builds the dashboard on that count and again when the sensor reports; when the estimate differs from the sensor's last count, the first build waits for the sensor for up to five seconds. Models without a cell count sensor, and estimates that match, are not delayed.
