- **The tool's colours come from one role table (`ui/palette.lua`)**:
  - The colours the tool pages, the menu and the shared controls draw used to name an EdgeTX theme constant at the site, and one constant stood for different things in different places. The sites now read a role named for what it means on screen (`text`, `muted`, `border`, `accent`, `panel`, ...), and each role holds the constant its sites used before, so nothing looks different. Fallbacks that cannot fire were dropped: every constant named first is exported by EdgeTX 2.11 and later. The table registers itself as `rfsuite.palette`, so a module loaded again on every page open reads it from there; measured with `bin/accounting`, most page builds cost 8 to 61 instructions more and Validate Sensors 69 fewer (its status colours are now resolved once), and the ELRS link page's target, 9 instructions above its cost before, is widened. The log graph's curve colours, the alignment page's 3D shading and the dashboard widget keep their own colours.
