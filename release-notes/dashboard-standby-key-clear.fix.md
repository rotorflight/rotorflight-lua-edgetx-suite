- **The standby screen is no longer built again during a connect when nothing on it changed (`widgets/dashboard`)**:
  - A connect clears the dashboard's render key several times -- at the reconnect edge, on each theme or preferences reload, when the battery's voltage bounds move -- and every clear built the standing standby screen again: on a TX15 eight standby builds per connect and disconnect, of which three were for a change of the information line. On EdgeTX up to 2.12.5, whose `lvgl.clear()` leaves native memory behind (fixed by EdgeTX #7997, merged after 2.12.5), each of those builds cost free memory. The standby built for the same key now stays; a new information line, language, zone size, layout or colour scheme still rebuilds it.
