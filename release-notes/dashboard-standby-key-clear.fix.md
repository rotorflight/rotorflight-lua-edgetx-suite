- **The standby screen is no longer built again during a connect when nothing on it changed (`widgets/dashboard`)**:
  - A connect clears the dashboard's render key several times -- at the reconnect edge, on each theme or preferences reload, when the battery's voltage bounds move -- and every clear built the standing standby screen again, about seven times per connect. On EdgeTX releases whose `lvgl.clear()` leaves native memory behind, each of those builds cost free memory and the radio grew slower over repeated connects. The standby built for the same key now stays; a new information line, language, zone size, layout or colour scheme still rebuilds it.
