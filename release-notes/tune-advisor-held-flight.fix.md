- **Tune Advisor no longer counts a flight twice, or drops older flights, when the flight controller was not cleared after it (`tasks/events/tune_capture.lua`, `lib/tune_history.lua`)**: when the model is armed again before the clear after a saved flight goes through, the clear is given up after link errors, or the widgets did not run meanwhile, the next reading also holds that flight. It is now saved marked as containing it (a `c(time, seconds)` line in the flight history file, naming it), and the page leaves the earlier flight out instead of counting it twice, so the flights before it count again as well. Nothing saved is removed. After a lost link the radio cannot tell a new pack from the same one, so that case is unchanged (#1167).
