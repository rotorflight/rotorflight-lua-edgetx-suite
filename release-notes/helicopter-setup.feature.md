- Add a separate Helicopter Setup wizard with the Configurator's 19-step sequence, individually accessible lazy steps, resettable per-FC history kept as bounded Lua data, and fresh model and physical checks. Compact and large layouts include mechanical references and live feedback: a live helicopter for the board orientation check, mode drawings that follow the actual switch input, and receiver, mode and profile learning from fresh FC channel snapshots. Swash and tail servos each offer the servo types made for them, with a picture of the servo and its pulse train, and a geometry correction switch on the same card that explains when to use it and to recheck pitch/limits. Receiver guidance points CRSF/ELRS pilots to ELRS Link, and the motor card explains how to prepare a new ESC in ESC Tools. The wizard requires MSP API 12.10 and shows printed serial socket names for known board designs. The swash servos are tested and centred on one page, with the tail centred beside them on large screens, and the control checks name the input they need and show the live stick. The receiver step adjusts the ExpressLRS link in place: flight controller and module values side by side, probe, either sync direction after a confirmation, and the module rate and ratio pickers. Staged MSP work, confirmed arming lockout, acknowledged override cleanup, independent timeout probes, safe Save/Discard and explicit interrupted-session recovery keep hosted operation bounded. At *Debug Level* INFO or DEBUG the wizard writes its loading, step, status, save and picture events to the Session Logs under `rfsuite.helicopter_setup`; at OFF it writes nothing. It takes over the Wizards entry from the Setup Assistant, whose code stays in the repository but is no longer reachable (`helicopter_setup`).
