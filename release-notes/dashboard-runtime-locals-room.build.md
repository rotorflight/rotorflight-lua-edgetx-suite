- **The dashboard's runtime has room under Lua's limit of 200 locals again (widgets/dashboard/runtime)**: its main chunk held exactly 200 active locals, so any pull request adding one more top-level local produced a file that does not compile. Helpers used only inside one group of functions (the MSP tick, the preference reload, the theme mode with the zone views, the telemetry read) now sit in `do ... end` blocks, which frees 26 slots at the tightest point; every function the widget calls compiles to the same instructions as before, and the file's own top level gains 16 instructions, run once at load. A new check, `bin/dashboard/verify_runtime_locals.lua`, fails once fewer than 10 slots are left (#1107).
